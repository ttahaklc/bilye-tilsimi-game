# Bilye Tılsımı

Zuma tarzı bilye atış oyunu. Unity **6000.5.3f1**, URP 2D, 100 bölüm / 10 dünya, 3 sonsuz harita, 7 dil (tr, en, zh, hi, es, ar, fr).

## Çalıştırma
1. Unity Hub > Add > bu klasör. Unity 6000.5.3f1 (iOS ve/veya Android Build Support ile).
2. `Assets/Scenes/SampleScene.unity` sahnesini aç, Play.
3. iOS: File > Build Profiles > iOS > Build, çıkan Xcode projesini Xcode'da aç.
4. Android: Bilye > Android hazırla, sonra Build Profiles > Android > Build (AAB).

Mağaza metinleri ve rehber: `AppStore/`.
